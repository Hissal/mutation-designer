# Mutation Designer

A browser-based visual workspace for recording mutation ideas for a body-horror roguelike first-person shooter. This is a design tool, not a runtime mutation authoring system.

## Confirmed requirements

- Each mutation has a positive and negative effect.
- Stable: positive only.
- Unstable: positive and negative.
- Corrupt: negative only.
- Volatile (formerly Rampant) is out of scope.
- Save designs and export definitions to files for handoff.

The supplied picker screenshot is visual reference. These written rules take precedence over its example labels and effects.

## Status

Repository foundation prepared. Design interview and UI prototyping are next. Storage, export formats, and interface choices are undecided.
